# Changelog

All notable changes to this app will be documented in this file.

---

## [1.0.0] - 2026-10-25

First release as FoyerLauncher. Forked from CleanFrame 0.6.1 (MIT), a home screen for Samsung Tizen TVs, renamed, relicensed as GPL-2.0-or-later for new work, and extended with an Android TV / Google TV app. The Tizen build keeps working, with a new package identity.

### Added
- **Android TV / Google TV app** (`android/`, package `io.github.nycoagung.foyerlauncher`, min API 26). A full-screen WebView serves the shared UI from the APK's assets on a fixed `https://appassets.androidplatform.net` origin; every page request is answered locally, so the page itself never reaches the network. Built with the SDK command-line tools by `android/build.sh` (no Gradle); `DEBUG=1` makes a WebView-debuggable build.
- **Home button without disabling anything.** `HomeKeyService` is an accessibility service that filters only `KEYCODE_HOME` and window-state changes from the TV's own home screen, and never reads window content. Short press opens FoyerLauncher; holding for 600 ms opens the TV's own home. When that home screen appears by itself (power-on, an app exiting to Home), FoyerLauncher is brought forward at most 3 times in 30 seconds, and never after the person chose the TV's home, until the screen turns off.
- **Works on any brand.** The TV's home screen is resolved from the default `CATEGORY_HOME` activity, and the service's event filter is set to that package at runtime. The Live TV app is whichever activity handles `ACTION_VIEW` for `vnd.android.cursor.item/channel`. The settings group and Back prompt are named "Google TV" or "Android TV" to match.
- **Android adapter** (`app/device-android.js`, bridge `window.FoyerAndroid`). Home starts with the installed ones of Live TV, YouTube, Netflix, Prime Video, Disney+, Kodi and VLC, falling back to the Play Store when none is installed. All apps lists Leanback apps, then non-system phone apps, with their own icons served from `/appicon/<package>.png`. Apple TV gets its mark under any maker's package name (`com.apple.atve.*appletv`).
- **Inputs sheet** listing the TV's physical inputs (HDMI, composite, component and others, using custom labels when set) and switching through `TvContract.buildChannelUriForPassthroughInput`.
- **Weather under the clock** (Android only): condition and temperature from Open-Meteo, at most every 10 minutes. Location from ipwho.is once a day; when DNS filtering blocks it, the city of the TV's time zone through Open-Meteo geocoding, matched on the same zone. Settings → Weather → Off stops all of it; °C or °F.
- **Google ambient photos** (Android only, off by default): Settings → Background → Photos → Google ambient streams random Featured photos from the Chromecast backdrop feed. `AmbientPhotos` downloads only from `ccp-lh.googleusercontent.com`, decodes at a capped size, renders the glass materials in Java at background priority, and keeps only the photo on screen, the previous one and the next in the cache directory.
- **Photo appearance** (Settings → Focus): Auto keeps each photo's measured inks; Light and Dark set one ink for the whole Home (stage classes `pa-light` / `pa-dark` with fixed `tr`/`br` inks, adaptive ink off), a pale veil or deepening shade over the photo, matching white or smoky glass veils, and in List a pale column behind the names. Light's colours apply to Home and its preview only, not the Settings panels. Stored as the `appearance` look; older saves read as Auto. 9 browser checks.
- **Shared UI:** 12-hour clock with AM/PM, Every minute rotation, Small/Medium/Large app names (scaled around each label's centre), and Roboto as a public font.
- **Matching logos for the TV's own apps, as part of setup:** `scripts/marks-from-tv.mjs --auto` finds the TV's home-screen apps without a bundled mark (Leanback apps and non-system launcher apps, minus the adapter's table, Apple TV and the Live TV app), pulls each APK (split APKs included) and converts its monochrome layer, else its adaptive-icon foreground, else a shipped `logo` resource, into a white SVG mark. Solid square tiles are rejected so those apps keep their own icon. It records what it made in `.local/marks-from-tv.json`, draws `.local/marks-preview.png` for the owner to review, and `--remove` drops marks. They go into the ignored `app/assets/icons/local/`; `scripts/build-icon-metrics.mjs` writes their metrics and package map to `local/marks.js`, and only `android/build.sh` adds them to a build.
- **Settings → About:** the version, What's New and the privacy policy (generated from `WHATSNEW.md` and `PRIVACY.md` by `scripts/build_about.py` into `app/assets/about.js`, so they can't drift; `npm run check` fails when it is stale), and Buy me a coffee, Windows-HQ.com and Source code links shown as QR codes with the address written out, since a TV may have no browser. Documents scroll with Up and Down; Up from the top returns to Back. On both platforms.
- Settings uses shorter rows when it has more than six groups, so Weather and About fit above the hint.
- **Bundled marks** for Kodi, VLC, Google Play, YouTube Music and Live TV.
- `npm run check:android`: 86 checks of the Android adapter in Chromium against a mock bridge, including app detection, Inputs, platform naming, weather fallbacks, ambient streaming and recovery after a failed stream. Added to CI.
- **Debloat for Android TV, Google TV and Fire TV** (`debloat/`). `debloat.sh` detects the brand from the TV's properties (`brands/brands.txt`) and works from `brands/common.txt` plus that brand's list: Sony, TCL, Hisense, Xiaomi, Philips, Sharp, Panasonic, Toshiba, Nvidia Shield, Chromecast with Google TV / Google TV Streamer, Walmart onn. and Amazon Fire TV. Each entry is bloat (recommended, hidden by default), optional (hidden when chosen, by group), keep or never (always refused, including `com.x.*` patterns). The more cautious verdict wins between lists, and single-source "bloat" counts only as optional. `--list` prints the choices grouped for the owner; `--include`, `--except`, single apps and groups narrow them; `--again` repeats the last choices; `--dry-run` previews. Apps are hidden with `pm disable-user`, never uninstalled, and each app's earlier state is recorded first. `restore.sh` brings back all, a group or one app, and leaves maker-disabled apps alone.
- **Research behind the lists** (`debloat/research/`): per-brand tables with a source for every package, CleanYourTV's 34 tested Sony lists (MIT), a list tested in daily use on one Sony, and `build-lists.py` (`npm run build:lists`) to regenerate them.
- **A restore script for each TV.** Every debloat run and install writes `my-tvs/<model>-<serial>/restore-my-tv.sh` from what was recorded on that TV: it re-enables each hidden app to its earlier state, gives the Home button back (keeping other accessibility services), removes FoyerLauncher with `--uninstall`, refuses a TV with a different serial number, and needs only adb. `my-tvs/` is ignored by Git and refused by `npm run check:public`.
- `npm run check:debloat`: 39 checks of the debloat, install and restore scripts and the generated restore script against fake TVs of eight brands. Added to CI.
- **Installing with an AI agent:** Installation needs an AI coding agent such as Claude Code. `docs/agent-android-setup-guide.md` takes it through the setup stage by stage: ask the owner for the TV's brand, model, platform, software version and IP address (typed or from a photo); turn on debugging (USB/network or Wireless debugging pairing); show the owner the apps that can be hidden and hide only their choices; install FoyerLauncher; confirm each result on the TV; and hand over the TV's restore script. The README gives the prompt to start it. The repository names no TV or address: the scripts take `TV_IP=<TV_IP>` (with an optional port), and `npm run check:public` fails if a tracked file contains a private network address.
- `npm run build:android`, and `android/install.sh` / `android/restore.sh`, which save the TV's accessibility settings to `my-tvs/<model>-<serial>/` before changing them and put them back exactly (an earlier record in `android/.local/` is moved there).

### Changed
- Renamed CleanFrame to FoyerLauncher throughout: globals (`FoyerDevice`, `FoyerQA`, `FoyerIconMetrics`, `FoyerWallpapers`, `FoyerAdaptiveInk`, `FoyerPrivateFontIDs`), the `foyer.home.v1` storage key, `FOYER_PUBLIC_FONTS`, and export names (`dist/FoyerLauncher-public-unsigned.wgt`).
- New Tizen identity: package `FoyerHome1`, application `FoyerHome1.FoyerLauncher`, widget id `https://foyerlauncher.local/app`. A TV with CleanFrame installed treats FoyerLauncher as a separate app.
- `assets/icons/metrics.js` now loads before the device adapters, so a local marks file can extend it.
- New app icon and Android TV banner in the Windows-HQ colours shared with FlickrSyncr: Material-style flat shapes on a white tile: a TV whose bezels form a blue (#007EEE) letter F, the rest of the TV in light blue, on deep navy for the banner. `npm run build:icons` (`scripts/build-app-icons.mjs`) draws them, including the Samsung `app/icon.png`.
- The bundled photo source is named FoyerLauncher (stored as `builtin`).
- Licence: GPL-2.0-or-later. CleanFrame's MIT notice is kept in `THIRD_PARTY_NOTICES.md` for the parts that came from it.

### Removed
- The upstream maintainer's machine-specific instructions and publication records.

### Notes
- Checked on a Google TV running Android TV OS 12: the service finds the TV's home screen and brings FoyerLauncher forward when it opens; Home starts with the installed Live TV, YouTube, Netflix, Prime Video, Kodi and VLC; weather shows through the time-zone fallback. `install.sh` and `restore.sh` were run on that TV, including a baseline captured while the service was already on. The physical Home button, hold-Home and power-on still need checking with the remote on this build. `npm run check`, `npm run check:public`, 349 browser checks and 86 Android checks pass.
